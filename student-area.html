Important security note

Static websites cannot protect private files by themselves.

Koyuncu Academy currently runs as a static website. A client-side password form would not be real security because files committed to a public repository can still be accessed directly. Private student materials should stay outside the public website repository.

Future architecture options

Realistic ways to protect student materials

Short-term

Keep private files outside the website and share them through Google Drive, OneDrive, Dropbox, Notion or another provider with access control.

Medium-term

Use a learning platform such as Google Classroom, Notion, MoodleCloud or Canvas. The website can link to the selected student portal.

Advanced

Build a separate authenticated app using Supabase Auth, Firebase Auth, Clerk, Auth0 or a backend with protected storage outside the public repo.

Current status

No login form yet.

No fake ID/password system has been added. Existing students will receive access instructions directly once the real protected solution is chosen.
