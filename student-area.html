Access model

Public learning content stays open. Full material stays protected.

Public visitor

Can read public resources, selected final results, code snippets, visual explanations and articles.

Registered user

Can create an account, request access, and later save public resources once the backend is active.

Approved student

Can access assigned course folders, PDFs, homework, full solutions, Python/Jupyter files, LaTeX and private visualizations.

Private library

Materials planned for approved students

  • Course folders by subject, topic, language and level.
  • PDF notes, homework, solution sheets and exam-preparation packs.
  • Python/Jupyter notebooks, LaTeX files, plots and visualizations.
  • Access assigned by student, group, course or individual material.

Cloudflare backend

Security belongs outside static HTML.

The private material system should use Cloudflare Workers, D1 and R2. Static pages introduce the product flow, while Workers verify login, approval status and file permissions before serving private downloads.
