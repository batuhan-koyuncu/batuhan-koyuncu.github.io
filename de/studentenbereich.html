Studentenbereich

Studentenbereich folgt.

Bestehende Schüler erhalten später direkte Zugangsinformationen für laufende Notizen, Hausaufgaben, Aufgabenblätter, PDFs und Unterrichtsmaterialien.

Wichtiger Sicherheitshinweis

GitHub Pages kann private Dateien nicht sicher schützen.

Diese Website ist statisch. Ein clientseitiges Passwortformular wäre keine echte Sicherheit, weil Dateien im öffentlichen Repository weiterhin zugänglich wären. Private Unterrichtsmaterialien sollten nicht in diesem öffentlichen GitHub-Pages-Repository gespeichert werden.

Zukünftige Optionen

Realistische Wege für geschützte Materialien

Kurzfristig

Private Dateien außerhalb von GitHub Pages speichern und über Google Drive, OneDrive, Dropbox, Notion oder ähnliche Anbieter freigeben.

Mittelfristig

Eine Lernplattform wie Google Classroom, Notion, MoodleCloud oder Canvas verwenden.

Fortgeschritten

Eine separate App mit echter Authentifizierung über Supabase, Firebase, Netlify Identity, Clerk, Auth0 oder ein Backend entwickeln.

Aktueller Stand

Noch kein Loginformular.

Es wurde kein falsches ID/Passwort-System eingebaut. Bestehende Schüler erhalten Zugangsinformationen direkt, sobald die echte geschützte Lösung gewählt ist.
