# Logo alani

Header logosu icin dosyayi buraya koy:

```text
stitch-export/assets/logo.png
```

Onerilen olcu:

- Yatay logo: yaklasik 320x80 px
- Seffaf PNG veya SVG'den export edilmis PNG
- Header icinde yukseklik otomatik `44px` olarak kullanilir

Dosya yoksa header otomatik olarak `Koyuncu Academy` yazisini gosterir.
