Lesson model

Flexible tutoring formats for different academic needs.

Not every student needs the same lesson structure. Koyuncu Academy separates diagnostic support, regular tutoring, intensive exam preparation and project-oriented academic workflow support.

Send an inquiryView tutoring subjects

Formats

Choose the format that matches the problem.

Diagnostic first lesson

A focused first meeting to inspect material, identify gaps, estimate difficulty and decide whether regular lessons or intensive preparation makes sense.

Regular tutoring

Weekly or biweekly support for lecture follow-up, problem sheets, concept building and gradual exam preparation.

Intensive exam preparation

Short-term preparation using topic lists, representative tasks, exam-style questions and revision priorities.

Project and report support

Academic workflow support for reports, Python/Jupyter notebooks, LaTeX, plots, data analysis and presentations.

Single-problem session

A single difficult exercise can be used to diagnose the missing concept and build a method for similar problems.

Study plan session

A planning-focused meeting can turn a broad exam or project into a realistic sequence of topics, tasks and milestones.

What affects the format?

Subject level and preparation effort matter.

The suitable format depends on course level, deadline, preparation time, file complexity, target exam and whether the request is conceptual tutoring, exam preparation or project workflow support.

Current booking process

Simple email-first workflow.

The first website version uses email inquiries instead of automated booking. Send your topic, deadline and materials first; then the best format can be discussed.

Before you write

Include the essentials in your first message.

Send the course or exam name, topic, deadline, current level, preferred language and one representative task or document. A precise first message makes the answer more useful.
