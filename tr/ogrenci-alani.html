Öğrenci Alanı

Öğrenci alanı yakında açılacak.

Mevcut öğrenciler ders notları, ödevler, problem setleri, PDF’ler ve materyaller için erişim bilgilerini doğrudan alacaktır.

Güvenlik notu

GitHub Pages gerçek güvenli dosya koruması sağlamaz.

Bu site statiktir. Sadece JavaScript ile yapılan bir şifre formu gerçek güvenlik değildir; dosyalar public GitHub reposuna yüklenirse erişilebilir kalabilir. Bu yüzden özel öğrenci dosyaları public GitHub repo içine yüklenmeyecektir.

Gelecek seçenekler

Materyaller nasıl güvenli paylaşılabilir?

Kısa vadeli çözüm

Google Drive, OneDrive, Dropbox, Notion veya benzeri araçlarda erişim kontrollü klasörler kullanmak.

Orta vadeli çözüm

Google Classroom, MoodleCloud, Canvas veya Notion gibi bir öğrenme platformu kurmak.

Gelişmiş çözüm

Supabase Auth, Firebase Auth, Auth0, Clerk veya özel backend ile gerçek kimlik doğrulamalı bir öğrenci portalı oluşturmak.

Şu anki durum

Sahte şifre formu eklenmedi.

Mevcut öğrenciler, gerçek güvenli çözüm belirlendiğinde erişim bilgilerini doğrudan alacaktır.
