# Lectures

Use this folder for public lecture pages on the website.

Recommended structure:

```text
lectures/
├── brownian-market-model.html
├── vector-calculus.html
├── elektrotechnik-4.html
└── quantum-mechanics.html
```

Each lecture page can link to:

- PDF lecture notes in `assets/pdf/`
- images and hand sketches in `assets/img/`
- Python-generated plots
- problem sheets and solutions
